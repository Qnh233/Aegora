关键边界

内容源FAQ 和 Skill 源内容由 Strapi 管理，运行时检索副本和向量在 PostgreSQL/pgvector。
会话存储会话、消息、反馈通过 Strapi 保存；会话并发锁、工具日志、审计日志、记忆写 PostgreSQL。
检索降级Embedding API 不可用时，FAQ 检索可降级为全文检索；Skill 自动召回会跳过。
工具执行只有整批工具全部只读且 parallel_safe 时才并行；混入写工具时串行执行。
